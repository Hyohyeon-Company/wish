# Application contribution rules

This is a public application repository. Keep private conversations, credentials, control-plane state and raw production data out of commits, Issues, PRs and Actions logs.

Read `docs/engineering.md` and actual package scripts before changes. Link a scoped domain Issue and use a short branch plus review-sized PR. Preserve approved domain/design behavior. Record test commands and observed results, not inferred success.

The assigned implementer merges only after the designated independent Reviewer's formal approval of the current head, resolved findings and protected-main CI success. Do not push directly to main or bypass protection. GitHub owns code/review records; the private team runtime owns execution and user decisions.
